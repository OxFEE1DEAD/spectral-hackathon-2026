решения: D-19 только после busy-poll, D-02 DPDK не делаем вообще

ПОРЯДОК ОБЯЗАТЕЛЕН [D-19]
  Сначала файл 11 (SO_BUSY_POLL + SO_PREFER_BUSY_POLL + napi_defer_hard_irqs
  + gro_flush_timeout). Они дают большую часть того же эффекта при НУЛЕВОМ
  риске воспроизводимости. Только потом AF_XDP.

ЧТО РЕАЛЬНО ПРОВЕРЯЕМ
  НЕ p50 (оценка выигрыша 1-3 us из 26 — 4-10%).
  А: режет ли AF_XDP p99.9, убирая softirq-планирование из RX-пути.
  Меряем ИМЕННО стадию S5->S6 (HW RX ts -> recvmmsg вернулся).
  Если S5->S6 не был крупнейшим spread'ом (файл 99) — не лезем вообще.

ФАКТЫ ПО ENA
  native AF_XDP с zero-copy: r2.7.0 введено, r2.13.0 переоткрыто,
  r2.16/2.17 расширено. Использовать >= r2.16.
  ограничения: нужен загруженный XDP-программа; только 4 КБ буферы;
  min RX buffer 2 КБ; MTU <= 3502 при 4K-страницах;
  ZC-каналы ТОЛЬКО с индексом очереди < половины максимума
  (32 канала -> ZC только на 0-15). Ядро 5.10+ (5.11+ для NEED_WAKEUP).

СКРЫТАЯ ЦЕНА, КОТОРУЮ НИКТО НЕ ЗАКЛАДЫВАЕТ
  AF_XDP обходит ARP / маршрутизацию / ICMP.
  Ethernet+IP+UDP заголовки и разрешение ARP пишем РУКАМИ.
  ~день работы с НУЛЕВЫМ выигрышем по латентности.
  Нужен fallback при неразрешённом ARP.

DPDK — НЕ ДЕЛАЕМ ВООБЩЕ [D-02]
  AWS публикует свой замер: p50 25.6 / p99 28.2 us на m8a.metal-24xl с DPDK.
  Настроенный kernel UDP отстаёт на 2-4 us = ~10% пути.
  Цена: vfio-pci забирает ENI целиком; нужен второй ENI, чтобы SSH выжил;
  судья ошибается порядком -> инстанс недоступен -> DQ.
  В райтап: цифра AWS как ПОТОЛОК + насколько близко подошёл kernel-путь.
  Это сильнее, чем рискованная реализация.

  Побочно: ENA LLQ (Large LLQ, дефолт с Nitro v4) толкает дескрипторы и
  первые 96/224 байта пакета в память устройства через write-combined BAR —
  это главный "DPDK-подобный" трюк, и он доступен ЯДЕРНОМУ драйверу
  бесплатно. Проверить ethtool -S | grep llq.

БЕНЧМАРК ЭТОЙ СТАДИИ
  только S5->S6 до/после + полный e2e для контроля, что ничего не сломали.
  Решение оставлять/выбрасывать принимается по p99.9 стадии S5->S6.
  Остаётся опциональным флагом, дефолт — kernel UDP.
