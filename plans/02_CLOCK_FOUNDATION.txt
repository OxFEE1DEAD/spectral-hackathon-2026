решения: D-15 (PHC + двунаправленная сумма)

ПОЧЕМУ ЭТО ПЕРВОЕ
  Не можем надёжно измерить кросс-хост латентность -> все 18 последующих дней
  оптимизируют шум и мы этого не заметим.

ШАГИ
  1. PHC. ENA >=2.10, включение модульным параметром phc_enable=1
     (devlink только на ядре >=6.17, в Ubuntu 24.04 ядро 6.8).
     Может потребоваться DKMS-сборка amzn-drivers — заложить время.
  2. chrony:
       refclock PHC /dev/ptp0 poll 0 delay 0.000010 prefer
       makestep 0 0            <- НИКАКИХ шагов во время прогонов
       maxslewrate <низкий>
     почему makestep 0 0: слю 500 ppm за 60 с = 30 us дрейфа. Прогоны держим
     10-30 с именно поэтому.
  3. ClockBound — интервал (earliest, latest) истинного времени на хост.
  4. Четыре независимых инструмента, все дешёвые, все в бандл КАЖДОГО прогона:
       chronyc tracking                              offset, root delay/disp
       /sys/bus/pci/devices/<bdf>/phc_error_bound    оценка Nitro
       clockbound                                    интервал истинного времени
       двунаправленный прогон                        см. ниже
     Полная граница на хост:
       CEB = |offset| + 0.5*root_delay + root_disp + phc_error_bound
     Парная = сумма по двум хостам. Печатать всегда.

  5. ДВУНАПРАВЛЕННАЯ ВАЛИДАЦИЯ (главный методический аргумент)
     Гоняем пайплайн в обе стороны одновременно: A->B и B->A, независимые
     пары producer/consumer, разные порты. c = смещение часов A-B.
       L_AB + L_BA           точно свободно от c, БЕЗ допущения о симметрии
       (L_AB - L_BA)/2 = -c  при симметрии -> независимая оценка смещения
     Сверяем вторую с ClockBound. Сошлись в пределах ~2us -> история про часы
     доказана двумя независимыми способами.
     вместо: RTT/2 — требует недоказуемого допущения о симметрии пути.

  6. ШУМОВОЙ ПОЛ ИНСТРУМЕНТА. Одиночный хост, изолированные ядра:
     воспроизвести числа из harness/README.md —
       p50 218 нс / p99 457 нс / p99.9 808 нс / p99.99 6935 нс
     Этот p99.99 ~7 us и есть шумовой пол. ВСЁ дальнейшее интерпретируем
     относительно него: заявить улучшение меньше него нельзя.

  7. Спросить у @spectral_challenge_bot URL публичного Claude-бейслайна.
     Прогон против него на нашем стенде = самый убедительный график,
     который вообще можно построить. Нужен рано, чтобы успеть.

ОЖИДАЕМАЯ ТОЧНОСТЬ PHC
  смещение единицы us; 5/95 перцентили за 15 мин редко вне +-2us;
  root dispersion 0.6-1.8 us.
  Против one-way ~26 us: ~8% смещения на p50, ~0 влияния на p99-p50.
  Т.е. для хвоста (за что и приз) PHC более чем достаточен.
